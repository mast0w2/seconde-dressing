# Logo Seconde — déclinaisons

24 fichiers : 4 mises en page × 6 déclinaisons de couleur, en SVG (vectoriel, redimensionnable à l'infini) et en PNG (2400px de large, fond transparent quand indiqué).

## Mises en page

| Nom | Quand l'utiliser |
|---|---|
| `vertical` | Format carré-ish : réseaux sociaux, tampons, packaging, signature |
| `horizontal` | Bandeaux : en-tête de site, e-mail, présentation, papier à en-tête |
| `icone` | La marque seule : favicon, avatar, pastille, watermark |
| `mot` | Le mot seul : quand le cintre est déjà présent à côté, ou en très petit |

## Déclinaisons de couleur

| Nom | Composition | Fond recommandé |
|---|---|---|
| `vert-fond-transparent` | Vert forêt + cœur sauge | Fonds clairs (crème, blanc, photo claire) |
| `creme-fond-transparent` | Crème + cœur sauge clair | Fonds foncés (vert forêt, photo sombre) |
| `blanc-fond-transparent` | Monochrome blanc | Photos, fonds colorés, impression 1 couleur |
| `vert-sur-creme` | Bloc crème, logo vert | Quand il faut un bloc autonome sur fond quelconque |
| `creme-sur-vert` | Bloc vert forêt, logo crème | Version « signature », la plus forte |
| `blanc-sur-vert` | Bloc vert forêt, logo blanc | Alternative plus contrastée à la précédente |

## Règles d'usage

- **Zone de protection** : garder autour du logo un espace vide au moins égal à la hauteur du cintre. Ne rien coller contre.
- **Taille minimale** : 24px de haut pour l'icône seule, 40px pour les lockups avec le mot (en dessous, l'étiquette n'est plus lisible).
- **Ne pas** : déformer les proportions, changer les couleurs hors palette, ajouter d'ombre ou de contour, recomposer l'espacement entre le cintre et le mot, mettre la version vert sur un fond foncé.
- **Sur photo** : utiliser la version blanche ou crème, sur une zone calme et suffisamment contrastée de l'image.

## Formats

- **SVG** : à privilégier partout où c'est possible (web, print, Canva, Figma). La police est intégrée dans le fichier — il se rend correctement même sur un poste où Cormorant Garamond n'est pas installée.
- **PNG** : 2400px de large, fond transparent pour les déclinaisons `fond-transparent`. Pour un besoin plus grand, repartir du SVG.

## Couleurs utilisées

| Rôle | Hex |
|---|---|
| Vert forêt | `#2e3a2c` |
| Crème | `#f4f1ea` |
| Sauge (cœur) | `#8b9a7a` |
| Sauge clair (cœur sur fond foncé) | `#c7d0b7` |
| Blanc pur | `#ffffff` |

## Typographie du logo

Cormorant Garamond, graisse 400 (Regular), en bas de casse, interlettrage +0.02em.
Police libre et gratuite : https://fonts.google.com/specimen/Cormorant+Garamond
